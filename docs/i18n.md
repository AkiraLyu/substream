# 界面语言

Substream 的桌面程序和 Chromium 扩展提供简体中文（`zh_CN`）和英语（`en`）。桌面程序按系统的界面语言优先级选择翻译，扩展跟随 Chromium 的界面语言。没有匹配的翻译时使用英语。

语言在桌面程序启动或扩展页面加载时确定。修改系统或浏览器的界面语言后，需要重新启动对应程序。语言选择不依赖正在浏览的网页，也不依赖语音模型的语言配置。

Linux 下可以通过 `LANGUAGE` 为单次启动指定界面语言：

```bash
LANGUAGE=en_US build/overlay/substream-overlay
LANGUAGE=zh_CN build/overlay/substream-overlay
```

Qt 使用 `QLocale::system().uiLanguages()` 读取语言优先级，区域格式仍由系统 locale 决定。扩展使用 Chromium 的语言选择和默认语言回退机制。接口行为见 [Qt 翻译加载说明](https://doc.qt.io/qt-6/qtranslator.html#load-1) 和 [Chromium 国际化接口](https://developer.chrome.com/docs/extensions/reference/api/i18n)。

界面翻译覆盖控件、运行状态和客户端错误提示。字幕内容、设备名称、标签页标题、模型路径以及外部程序返回的原始诊断保持原文。命令行识别程序的日志和错误信息使用英语，协议字段与状态值不随界面语言变化。

## 桌面程序

桌面代码使用 Qt 的 `tr()`；不属于 `QObject` 的函数使用 `QCoreApplication::translate()` 并指定上下文。源文本使用英语，翻译文件位于 `apps/overlay/i18n/`。

`Translations` 在创建窗口前加载翻译，并在程序运行期间保留翻译对象。应用翻译编译为 `.qm` 文件并嵌入程序，无需单独安装。Qt 标准对话框使用系统安装的 Qt 翻译包。

修改可见文本后，更新翻译目录：

```bash
cmake -S apps/overlay -B build/overlay -G Ninja
cmake --build build/overlay --target update_translations
```

在 Qt Linguist 或文本编辑器中补齐 `substream_zh_CN.ts` 的翻译，再重新构建程序。`substream_en.ts` 只保存英语单复数形式，其余英语文本直接使用代码中的源文本。

含变量的句子使用 `%1`、`%2` 等占位符，不要拼接需要翻译的句子片段。数量表达使用 Qt 的复数接口，例如：

```cpp
tr("%n thread(s)", nullptr, threadCount)
```

增加语言时，在 `i18n/` 中添加对应 `.ts` 文件，并将其加入 `CMakeLists.txt` 的 `qt_add_translations()`。源文件属于独立库时，也应将库目标加入 `SOURCE_TARGETS`，确保更新工具能提取其中的文本。

## 浏览器扩展

翻译文件位于 `browser/extension/public/_locales/<locale>/messages.json`。`manifest.json` 以英语作为默认语言，构建脚本将全部翻译目录复制到扩展包中。

TypeScript 通过 `src/i18n.ts` 的 `message()` 读取文本，消息名称由英语目录推导为类型。弹窗静态元素使用 `data-i18n`，由 `localizeDocument()` 填入文本并设置文档语言。所有文本通过 `textContent` 显示，不将翻译或替换参数作为 HTML 执行。

含变量的文本使用 Chromium 的命名占位符，并通过 `message()` 的第二个参数传值。新增消息时先补充英语目录，再添加中文翻译。不要在调用处保留另一份默认文本。

增加语言时，使用 Chromium 支持的 locale 名称创建目录。未翻译的消息由浏览器回退到英语，不需要修改业务逻辑或增加语言判断。

## 验证

```bash
cmake --build build/overlay --parallel 2
ctest --test-dir build/overlay --output-on-failure

cd browser/extension
npm run format:check
npm run check
npm run build
npm test
```

自动检查覆盖桌面语言选择、英语回退、单复数和扩展翻译占位符。调整界面布局后，还需分别检查中文和英语，确认长文本没有遮挡控件或被截断。
